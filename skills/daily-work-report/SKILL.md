# 日报周报

## 核心规则

- 使用中文输出。
- 日报按项目分组，每个项目独立编号，默认格式为 `1、【标签】内容`。
- 周报必须先读取缓存，再做汇总。
- 删除缓存只在用户明确要求时执行。

## 缓存位置

- 读取与写入缓存文件：`~/.codex/memories/daily-report-cache.md`
- 周报与缓存细则参考：`references/report-cache.instructions.md`
- 如果缓存文件不存在，视为"当前无缓存"，按空白状态开始；不要报错。
- 如果用户已手动清空周缓存，不要恢复旧内容，不要从其他工具目录回填历史缓存。

## 日报流程

1. 识别当前项目。
   - 优先使用当前工作区目录名（Claude Code 启动时的 cwd）。
   - 如果项目名不明显，再看 `package.json` 里的 `name`。

2. 收集当天已完成或已验证的工作项。
   - 优先使用本次会话内可观测到的事实：
     - 已应用的文件编辑（Edit / Write 工具产生的改动）
     - 用户给出的明确确认或反馈
     - 执行成功的命令输出
   - 必要时调用 `git log --since=midnight --pretty=oneline`（或等价 PowerShell 命令）补充未在会话中提及的提交，仅作为参考来源，仍按下方 Git 噪音过滤规则筛选。
   - 默认排除纯环境噪音、临时调试、一次性试错和无沉淀价值内容，除非用户明确要求保留。

3. 读取缓存并合并当天其他项目内容。
   - 同一天多个项目的日报需要一起输出。
   - 每个项目独立成组、独立编号。

4. 输出最终日报。
   - 扁平化，不嵌套。
   - 每条一句，尽量短。
   - 标签优先使用：`【完成】`、`【修复】`、`【重构】`、`【优化】`、`【验证】`、`【排查】`、`【支持】`。

5. 将最终日报追加写入缓存。
   - 如果缓存文件不存在，则先创建再写入（含父目录）。
   - 缓存层级固定为：
     - `## 2026-W15`（ISO 周次）
     - `### 2026-04-10`（日期）
     - `#### 项目名称`
   - 同一天同一项目重复触发时，把新条目并入原项目标题下，重新从 1 开始顺序编号；不要保留作废条目。

## 周报流程

1. 先读取 `~/.codex/memories/daily-report-cache.md`。
   - 如果文件不存在或为空，明确告诉用户当前没有可汇总的日报缓存，并询问是否要先生成日报。
2. 默认汇总当前周，除非用户明确指定周次。
3. 只能基于缓存日报生成周报，不补充虚构内容。
4. 输出两份格式不同的独立周报。
5. 具体格式要求严格遵循 `references/report-cache.instructions.md`。

## 删除缓存

- 只删除用户明确指定的周记录或日期记录。
- 如果删除范围不清楚，先询问再删。
- 用户手动清空整份缓存文件也是合法操作，不要自动恢复历史内容。

## 质量要求

- 只写真实完成的工作，不虚构。
- 相似工作要合并，不拆成很多碎条。
- 不写寒暄、不写空话、不写过程性废话。
- 默认不要输出英文，除非用户明确要求保留英文原文。
- **语言果断简洁**：每条尽量一句话点到为止，**不要在括号里堆细节**（深色玻璃 / 两栏分组 / 多少行 / 哪几个文件 / 字段列表 / 类名等实现细节都不写）。
- **只记项目工作**：日报范围限定在"识别到的当前项目"内。个人工具、CLI 配置、skill / 编辑器 / shell 设置、跨项目通用脚手架等与本项目无关的事项不要写进日报。
- **避免模糊或带返工意味的词**：不要使用 `重做` / `重写` / `重新做` / `推倒重来` / `翻新` / `整改` 这类词，会让产出听起来像之前做错了。改用更中性的词，例如 `改版` / `升级` / `调整` / `优化` / `完善`；如果确实是结构性改造，用标签 `【重构】` 即可，描述里不再叠加"重写"。

## 日报过滤补充规则

- 默认不要把 Git 操作当作日报事项记录，例如"完成代码提交 xxxx"、"同步远端分支"、"merge / pull / push 成功"等；除非用户明确要求记录版本控制操作，或该操作本身代表业务交付节点。
- 默认不要把例行 lint / format / type-check / test 命令当作日报事项，例如"通过 oxlint"、"执行格式化"、"检查变更文件"等；除非该校验验证了一条有意义的业务流程、抓出 / 修复了具体问题，或用户明确要求记录命令级证据。

## 输出风格示例

```
今日日报（2026-05-19）

#### 华能 portal
1、【完成】注册页 UI 重做，深色玻璃卡片 + 两栏分组布局
2、【重构】拆出 useRegister composable，Register.vue 缩减到 30 行 script setup
3、【优化】axios 拦截器统一 code 判断与错误 toast，业务层不再写 `code === 0`
4、【优化】公钥与 app title 迁移到 .env，加密工具收口到 utils/crypto.ts
```
